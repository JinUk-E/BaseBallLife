# 킥루 분석과 야구판 적용

## 공식 자료에서 확인한 구조

킥루는 선수 한 명의 축구 커리어를 다루는 무료 브라우저 시뮬레이션이다. 포지션과 스타일을 정하고 훈련, 출전, 이적, 대표팀 활동을 거쳐 은퇴까지 기록을 쌓는다. 가입 없이 이용하며 저장 파일을 다른 기기로 옮길 수 있다. [공식 서비스 소개](https://kickru.com/about)

공식 가이드는 선수 생성 시 이름·국적·시작 국가·포지션과 후보를 선택한다고 설명한다. 시작 후보의 오버롤은 45이고 여섯 능력치 합은 240이다. 시즌 진행 중 훈련·계약·진로를 선택하며 나이, 출전, 활약, 건강, 숨은 특성이 성장에 관여한다. 잠재력은 상한이지 성장 보장이 아니다. 은퇴 기록은 일일 랭킹에 반영되며 발롱도르, 최고 오버롤, 개인상, 공격포인트 순으로 비교한다. [공식 게임 가이드](https://kickru.com/guide)

## 확인 범위

공식 소개·가이드와 메인·랭킹 페이지의 공개 텍스트를 2026-10-14 확인했다. 메인에는 커리어 로딩 상태가 표시됐고 실제 플레이 화면을 조작하지 못했다. 따라서 경기 시뮬레이션 산식, 화면 배치, 이벤트 빈도, 광고 노출, 실제 플레이 시간, 성장 확률은 미확인이다. 아래의 재미 분석은 공개 구조에서 도출한 해석이며 실측 사용자 평가가 아니다.

## 구조에서 읽히는 재미

**평범한 출발과 긴 상승 곡선.** 처음부터 완성된 스타보다, 자신의 선택으로 선발 자리를 얻고 기록을 경신하는 변화가 서사를 만든다. 야구판은 2군에서 1군 주전으로 올라가는 과정으로 이를 표현할 수 있다.

**능력과 기회의 분리.** 재능이 있어도 출전이 부족하면 성장하지 못하는 구조는 계약 선택에 이유를 준다. 야구에서는 타석과 투구 기회를 성장의 자원으로 사용한다.

**누적 기록이 만드는 애착.** 단일 경기의 승리보다 여러 시즌의 경력과 은퇴 결과가 반복 플레이의 목표가 된다. 야구판에서는 첫 안타, 첫 승리, 커리어 최고 시즌, 통산 기록을 기억할 사건으로 만든다.

**짧은 입력으로 긴 시간 진행.** 자동 경기와 중요한 선택의 결합은 짧은 접속에 적합할 가능성이 있다. 실제 원작 소요시간은 확인하지 않았으므로 야구판의 목표 시간은 자체 검증한다.

## 야구로 옮길 때 달라져야 할 것

| 원작의 확인 요소 | 야구판 제안 | 바꾸는 이유 |
| --- | --- | --- |
| 포지션과 스타일 | 타자 포지션·타격 스타일, 선발투수 스타일 | 서로 다른 선수 인생을 제공 |
| 출전 시간 | 타자의 타석, 투수의 선발 기회·투구량 | 야구에서 기회의 단위가 다름 |
| 이적과 계약 | 주전 가능성, 경쟁자, 연봉, 계약 기간 | 출전과 보상의 선택을 드러냄 |
| 시즌 기록 | 타율·출루율·장타율, 평균자책점·탈삼진 | 결과를 야구의 언어로 읽게 함 |
| 은퇴와 랭킹 | 개인 명예의 전당, 역할별 커리어 평가 | 타자와 투수의 수치를 직접 비교하지 않음 |

원작 수치, 이름, 화면, 문구를 복제하지 않는다. 특히 숨은 성장 요소를 그대로 늘리기보다, 예상 성장 범위와 출전 전망을 보여 선택 결과를 이해할 수 있게 한다.
