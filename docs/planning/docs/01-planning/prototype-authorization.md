# 검증용 게임 구현 범위

사용자는 2026-10-14 “우선 게임 만들어줘 그래야 검증이 가능하니까”라고 요청했다. 이를 플레이 가능한 검증용 구현 착수 지시로 반영한다. 정식 기획 동결과 외부 검토를 완료했다고 간주하지 않으며, 사용자 요청에 따라 프로토타입을 먼저 만든다.

## 최초 빌드 v0.1

엔진은 설치 없이 실행할 수 있는 HTML·CSS·JavaScript로 한다. 별도 서버 API나 패키지 의존성 없이 브라우저에서 동작한다. 신규 웹 게임은 `dugout/dist/`에 작성한다. 기존 기획 문서는 보존한다.

- 타자·선발투수 각각 3개 스타일, 구단 선택.
- 주간 훈련·회복, 능력 성장, 피로, 주전 경쟁.
- 8개 가상 구단의 주간 경기 결과·순위와 개인 기록.
- 16주 시즌, 시즌 종료 계약 선택, 최대 3시즌 뒤 커리어 요약.
- 선택형 사건, 시즌·통산 기록, 저장·가져오기·내보내기.
- 모바일·PC 화면, 규칙과 단기 검증 범위 안내.

현실 리그 규정, 포스트시즌, 실제 로스터, 18~40세 전체 생애, 해외 진출은 이 빌드에서 제외한다. 화면에서 3시즌 체험판임을 명시한다.

## 사용자 승인 확장 v0.2

2026-10-14 사용자는 생성 때 정하는 잠재력과 회차별 성장 차이, 이후 수비 위치 선택, 선발·중계·마무리, 부상·성장 보조 아이템, 한국·일본·미국의 현재 구단 이름을 요청했다. 내부 무료 플레이 용도로만 사용하고 외부에는 발표하지 않는다는 조건을 반영한다.

- 성장 상한·성장 속도·회복력을 생성 시 무작위 고정한다. 과훈련·부상으로 능력 감소가 가능하다.
- 수비 8개 위치와 지명타자, 투수 3개 보직을 주간 1회 변경한다.
- 회복·성장·부상 예방 아이템을 무료 게임 포인트로 구매·사용한다.
- KBO 10·NPB 12·MLB 30개 구단 중 선택하고 시즌 종료 후 국내외 이적한다. 구단 명칭만 실제 자료를 반영하며 일정·능력·경쟁·계약은 단순화한 게임 값이다.
- v1 저장 검증과 기록 보존 전환을 제공하고 이전 원본을 별도 보관한다.

영향도는 L이다. 핵심 성장·경기·저장 규칙이 바뀌므로 규칙 시험과 브라우저 플레이를 확인한다. 정식 기획 동결이나 Claude 모델 실행 완료를 의미하지 않는다. 코드 실행 주체는 Codex이며 팀 역할을 나누어 구현·데이터 확인·독립 검증을 수행한다.

## 사용자 피드백 확장 v0.3

2026-10-15 사용자는 부상 능력 감소 완화, 어린 나이의 빠른 성장과 30세 이후 유지·하락, 실제 계약 구조 조사·적용, 고교 시작, 국제대회 후속 개발 일정, 실제 경기 수와 일정 반영을 요청했다. v0.2의 3시즌 제한과 매년 자유 이적을 이 요청에 맞춰 변경한다. 프로토타입의 반복 제작을 계속한다는 승인 범위이며 외부 공개는 하지 않는다.

- 고교 16~18세 3년 및 KBO 지명 입단, 또는 19세 프로 시작. 40세 시즌까지 진행한다.
- 부상 영구 손실은 발생 시 관련 능력 최대 2개, 시즌 전 능력 합계 최대 2로 제한한다. 고피로·재활 기간의 반복 영구 차감은 없앤다.
- 10대·20대는 성장하고 30세부터 잠재력·회복력·누적 부상에 따라 유지·완만한 노화를 적용한다. 성장권은 30세 이후 유지 보조로 작동한다.
- 보류권과 연봉 갱신을 자유 이적에서 분리한다. 리그별 첫 FA·재FA 요건, 잔여 계약, FA 행사 유보와 1~4년 계약을 적용한다. 서비스 일수·보상·로스터·국적 제약은 명시적으로 간소화한다.
- 2026 KBO·NPB·MLB 공식 날짜·대진을 사용한다. 2026 실제 미소화 경기와 서스펜디드 처리 예외를 출처 문서에 남긴다. 미래 연도는 가상 템플릿으로 구분한다.
- 고교는 가상 8팀·28경기이고 고교 통산은 프로 기록에서 분리한다. 국제대회는 이번 경기 기능에 포함하지 않고 조사·버전별 완료 기준을 개발 계획에 기록한다.
- v1/v2 이전은 기존 나이·성적과 진행 중인 16주 시즌을 보존한다. 이후 시즌부터 새 경기 일정을 적용한다. 이전 버전별 원본을 별도 백업한다.

## 구현 분리와 검증 책임

`core.js`는 DOM·네트워크 없이 시드 난수와 상태 전이를 처리한다. `app.js`는 입력·화면·기기 저장을 처리한다. `styles.css`는 화면 구성만 담당한다. 게임 규칙 시험은 Node 내장 테스트로 실행한다. 소유권: 게임플레이 담당은 core.js, 조율자는 UI·패키징, 테스트 담당은 tests/.

## 검증

타자와 투수의 완주, 사건 선택·재접속, 기록의 불변 조건, 저장 복원, 훈련 선택 효과를 확인한다. 실제 재미 평가는 사용자의 플레이 후 조정한다. 배포가 환경 제한으로 막히면 로컬에서 실행 가능한 파일을 제공한다.

## GitHub Pages 공개 배포 승인

2026-10-27 사용자는 현재 야구 게임 저장소를 공개로 전환하고 GitHub Pages로 배포하도록 요청했다. 이전 버전의 내부용·외부 비공개 조건은 이번 공개 배포 요청으로 변경한다. `JinUk-E/BaseBallLife`의 `dist/`를 공개 웹 게임으로 배포하고, `main` 변경 시 규칙 검증을 통과한 버전만 자동 배포한다.
