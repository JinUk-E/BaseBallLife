# 야구 커리어 요구사항

P0는 핵심 반복 검증, P1은 첫 완성판에 필요, P2는 이후 편의 확장이다. 모든 구현 상태는 대기다.

| ID | 우선순위 | 요구사항 | 수락 기준 |
| --- | --- | --- | --- |
| FR01 | P0 | 선수 생성 | 스타일별 강약점이 다르고 역할 내 초기 예산이 같음. 첫 시험은 외야수만 제공 |
| FR02 | P0 | 주간 계획 | 진행 전 대상 능력·예상 피로 구간을 확인하고 결과에서 변화를 구분할 수 있음 |
| FR03 | P0 | 출전 경쟁 | 출전 전망과 실제 기회를 분리하고, 미출전 2주 뒤 이유·목표가 표시됨 |
| FR04 | P0 | 자동 경기 | 한 번 진행한 주의 기록이 한 번만 누적되며 팀 결과와 개인 기록이 모순되지 않음 |
| FR05 | P0 | 결과 해석 | 출전, 성적, 능력, 감독 평가 변화가 서로 구분됨. 단기 부진이 능력 영구 감소로 표시되지 않음 |
| FR06 | P0 | 사건 선택 | 발생 조건을 만족할 때만 표시, 하나의 사건이 중복 적용되지 않음. 첫 시험 최소 3개 |
| FR07 | P1 | 투수 커리어 | 선발 일정·투구량·회복이 타자 기회와 분리됨. 다음 선발 날짜와 훈련별 준비 상태를 표시. 승패만으로 성장하지 않음 |
| FR08 | P1 | 시즌 진행 | 8구단 각각 112경기, 전체 448경기의 결과 집계와 승패가 일치. 결승 기록은 정규시즌과 분리 |
| FR09 | P1 | 계약 | 최대 3개 제안에 보상·경쟁·역할을 표시. 제안이 없어도 육성 계약 또는 은퇴로 진행 가능 |
| FR10 | P1 | 통계 | 타율·OPS·ERA·WHIP이 원시 기록에서 계산됨. 분모 0은 ‘—’, 투구 5아웃은 1⅔이닝으로 표시 |
| FR11 | P1 | 저장 | 확정된 주와 미응답 사건의 상태·기록이 재접속·내보내기·가져오기 뒤 동일. 사건 중복 적용 없음. 손상 파일이 기존 기록을 덮지 않음 |
| FR12 | P1 | 은퇴 | 최소 1시즌 이후 자진 은퇴 및 40세 시즌 종료 은퇴 가능. 통산·최고 시즌·이력이 보존됨 |
| FR13 | P1 | 빠른 진행 | 최대 4주를 진행하고 응답이 필요한 사건 전에 정지. 중간 주 기록 열람 가능 |
| FR14 | P1 | 회복과 역할 | 부상 중에도 시간이 진행되고 복귀 상태가 설명됨. 2군 실적은 1군 통산과 분리 |
| FR15 | P1 | 장기 콘텐츠 | 5계열·첫 시즌용 최소 12개 사건과 반복 억제 조건이 정의됨. 수비주루형의 시즌·은퇴 요약은 기용 평가와 주루 성과를 우선 표시 |
| FR16 | P2 | 공유 카드 | 사용자 요청 시 은퇴 요약을 이미지로 내보냄. 온라인 자동 게시 없음 |

## 비기능 목표

모든 수치는 검증 전 목표다. 개발 환경과 측정 기기는 기획 확정 후 선정한다.

| 항목 | 목표와 검증 방법 |
| --- | --- |
| 모바일 화면 | 폭 360 CSS px에서 핵심 화면 가로 스크롤 없음 |
| PC 화면 | 폭 1280 CSS px에서 기록 표와 진행 행동이 모두 사용 가능 |
| 반응 | 선정한 기준 기기에서 주간 진행 완료까지 1초 이내, 늦으면 처리 상태 표시 |
| 가독성 | 색 외의 텍스트·아이콘으로 상태 전달, 모든 핵심 통계에 설명 제공 |
| 안정성 | 장기 시험 100개 커리어에서 진행 막힘·음수 기회·기록 중복·NaN 없음 |
| 수치 일관성 | 개인·팀 득점, 승패, 안타 구성, 통산 계산의 불변 조건을 자동 검증 |

재미 평가는 [게임 개요](../00-inception/project-brief.md)의 탐색적 기준을 따르며 기능 수락 기준과 구분한다.
