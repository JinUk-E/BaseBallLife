# 야구 커리어 실행 백로그

구현은 아직 착수하지 않았다. 역할은 game-ai-team 정의 기준의 향후 담당 제안이며 실제 호출·완료를 의미하지 않는다. 엔진과 인력 확정 전에는 일정을 산정하지 않는다.

## 후속 결정

사용자는 타자·투수 개인 커리어 방향을 선택했다. 첫 완성판의 투수를 선발로 제한하는 세부 범위는 제안이다. 웹은 가정이며 특정 엔진을 선택하지 않았다.

팀 저장소 등록·기록 동기화는 현재 세션의 쓰기 권한 때문에 미완료다. 실제 구현 착수 전에는 팀 규칙이 요구하는 검토·확정 기록을 원본 저장소에서 사용할 수 있어야 한다.
