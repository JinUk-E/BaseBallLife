# 야구 커리어 게임 개요

## 한 문장 컨셉

무명 신인 한 명의 훈련과 계약을 선택하며, 출전 기회를 기록으로 바꾸고 은퇴 때 자신의 야구 인생을 돌아보는 커리어 시뮬레이션.

## 기본 정보

| 항목 | 제안 |
| --- | --- |
| 가제 | 더그아웃에서 명예의 전당까지 |
| 장르 | 싱글플레이 선수 육성·커리어 시뮬레이션 |
| 플랫폼 | 모바일 우선 웹, PC 브라우저 지원을 가정 |
| 타깃 | 선수 성장과 야구 기록을 좋아하고 짧게 여러 번 접속하는 이용자 |
| 조작 | 선택지와 진행 버튼, 직접 투구·타격 조작 없음 |
| 시간 목표 | 한 번 접속 3~5분, 시즌 기본 진행 5~10분. 모두 검증 전 목표 |
| 선수 인생 | 18세 시작, 최소 1시즌 뒤 자진 은퇴 가능, 최대 40세 시즌 종료 |
| 커리어 속도 | 초기에는 주별 진행, 반복 구간은 최대 4주 진행. 전체 소요시간은 시험 후 확정 |
| 엔진·배포 | 미정. 기획 승인 후 팀 설계 단계에서 결정 |

## 핵심 재미 가설

1. 높은 능력치와 많은 출전 기회 중 무엇을 먼저 확보할지 고민한다.
2. 같은 시즌에도 장타자, 수비형 타자, 제구형 투수가 서로 다른 성공을 경험한다.
3. 작은 선택이 누적돼 자기만의 커리어 이야기와 기록표가 만들어진다.

핵심 질문은 “다음 경기에서 무엇을 누를까”보다 “다음 시즌에 나는 어떤 선수가 될까”다. 매주 계획은 즉시 성적과 장기 성장에 다른 영향을 주고, 계약은 출전·안정·보상 사이의 선택을 만든다.

## 검증 목표

첫 프로토타입은 타자 6주 분량이다. 훈련·회복 선택, 주전 경쟁, 경기 요약만으로 재미가 성립하는지 확인한다. 장기 성장, 세이브, 전체 리그를 한꺼번에 만들지 않는다.

사용자 확정 후 실시할 탐색적 플레이테스트 기준:

- 테스트 참가자 5명 중 4명이 안내 후 2분 안에 첫 주를 진행한다.
- 5명 중 4명이 자신이 고른 훈련의 이득과 손해를 한 가지씩 설명한다.
- 5명 중 3명이 6주 종료 후 다른 선택으로 다시 해보겠다고 답한다.
- 선택별로 같은 초기 조건의 여러 난수 시드를 비교했을 때, 회복·성장·출전 중 의도한 지표가 구분된다. 정확한 효과 크기는 밸런스 실험으로 정한다.

이 기준은 소규모 방향 검증이며 시장 성공이나 장기 잔존율의 증거가 아니다. 미달하면 콘텐츠를 늘리기 전에 선택 구조를 수정한다.

전체 결과와 별도로 미출전 경로를 검증한다. 본 시험에 해당 사례가 없으면 미출전 상태의 시험 시나리오를 제공한다. 5명 중 4명이 출전하지 못한 이유와 다음 목표를 설명하고, 3명이 그 상태에서 한 번 더 계획을 선택하겠다고 답해야 한다. 이 기준이 미달이면 전체 재플레이 의향이 통과해도 벤치 경로는 재설계한다.

투수 시험에서는 같은 피로 상태에서 다음 선발이 1일 뒤인 상황과 5일 뒤인 상황을 비교한다. 두 상황의 예상 준비 상태를 보고 5명 중 4명이 훈련·회복의 차이를 설명하고, 3명이 등판 일정 때문에 선택을 바꾼 이유를 설명하는지를 확인한다. 결과 통계만 다르고 선택 이유가 같다면 투수 체감 검증을 통과한 것으로 보지 않는다.

## 제작 전제

담당 인원과 일정은 미정이므로 날짜나 인일을 약속하지 않는다. 첫 완성판은 가상 국내 리그와 기본 커리어로 제한한다. 투타 겸업, 해외 리그, 온라인 랭킹은 검증 이후 확장 후보다.
