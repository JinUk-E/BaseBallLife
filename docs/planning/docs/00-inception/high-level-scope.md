# 야구 커리어 개발 범위

## 첫 재미 검증

타자·외야수 1포지션, 6주, 주간 계획 4계열, 주전 경쟁, 경기 요약, 최소 3개 사건으로 구성한다. 저장·연간 리그·전체 커리어는 넣지 않는다. 6주 종료 시 임시 프로토타입임을 알리고 다시 시작한다. 이 단계는 완성 게임이 아니다.

타자 검증 통과 뒤 선발투수 6주 시험을 별도로 진행한다. 그 다음 타자와 투수가 각각 한 시즌을 마칠 수 있는 통합판으로 확장한다.

## 첫 완성판에 포함

| 항목 | 경계 |
| --- | --- |
| 선수 | 타자 8포지션 또는 선발투수, 각각 스타일 3개 |
| 리그 | 가상 국내 8구단, 112경기, 상위 2팀 결승 |
| 육성 | 주간 계획, 피로·컨디션, 성장과 노화, 경미·중간 부상 |
| 기회 | 추상화된 2군, 1군 경쟁, 역할 변화 설명 |
| 커리어 | 데뷔, 1년 계약, 국내 이적, 은퇴 |
| 기록 | 역할별 시즌·통산 기록, 개인 시즌 업적, 기기 내 명예의 전당 |
| 사건 | 5계열, 첫 시즌용 최소 12개 |
| 저장 | 자동 저장, 내보내기·가져오기 |
| 화면 | 모바일 우선, PC 지원, 통계 설명 |

## 제외

실시간 타격·투구 조작, 3D 경기 연출, 구단 운영, 실제 선수·구단 데이터, 실시간 대전, 결제, 계정·클라우드 저장, 온라인 랭킹은 첫 완성판 범위에 없다. 전체 NPC 선수들의 장기 커리어와 실제 프로리그 규정 재현도 제외한다.

## 확장 판단 시점

| 후보 | 진행 조건 |
| --- | --- |
| 해외 진출·국가대표 | 국내 커리어가 반복 플레이를 유도함을 먼저 확인 |
| 구원투수·마무리·투타 겸업 | 타자와 선발투수의 서로 다른 기회 구조 검증 |
| 리그 개인상·온라인 명예의 전당 | NPC 기록·역할별 평가·제출 검증 범위를 별도로 설계 |
| 다년 계약·트레이드 | 1년 계약에서 출전과 보상의 선택이 성립 |
| 공유 카드·멀티 슬롯 | 기본 저장의 복원과 장기 커리어 안정성 확인 |

사용자는 타자·투수 개인 커리어 방향을 선택했다. 플랫폼·엔진, 현실 리그 재현 수준, 인력·일정은 아직 확정되지 않았다. 현재 초안은 웹·가상 리그·타자와 선발투수 제안으로 일관되게 작성했다.
