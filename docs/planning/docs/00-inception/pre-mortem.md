# 야구 커리어 실패 가정

| 실패 시나리오 | 조기 신호 | 기획 대응과 확인 시점 |
| --- | --- | --- |
| 선택 없이 다음 주만 누르는 게임이 됨 | 시험자가 훈련의 비용을 설명하지 못함 | 타자 6주 단계에서 중단하고 선택 효과를 다시 설계 |
| 출전하지 못해 아무 일도 생기지 않음 | 2주 이상 기록과 목표가 모두 정체 | 감독 피드백, 2군 성장, 4주 진로 면담. 첫 시험에서 관찰 |
| 타자와 투수를 같은 성장식으로 처리 | 투수가 매 경기 던지거나 승수만으로 성장 | 투수 6주 별도 검증, 기회와 투구 부담 분리 |
| 개인 기록과 팀 결과가 모순 | 홈런·타점이 팀 득점과 양립 불가 | 시즌 통합 전에 경기·개인 기록 일관성 검증 |
| 현실 야구 전체를 만들다가 완성 못 함 | 해외 리그·전 선수 로스터가 핵심 루프보다 먼저 필요해짐 | 가상 8구단과 개인 업적만 포함, 전체 NPC 커리어 제외 |
| 기록이 저장 복원 후 변함 | 재접속으로 주간 결과가 바뀌거나 기록이 중복 | 확정 주의 복원·중복 방지 검증을 전체 커리어보다 먼저 수행 |
| 랜덤 부진과 부상이 억울함 | 선택 이유보다 난수 탓만 하게 됨 | 기대 범위·최근 평가·건강 경고 표시, 초기 영구 손상 제외 |
| 기록 화면이 초보자에게 난해함 | 첫 경기 뒤 의미를 모른 채 이탈 | 대표 지표와 설명 우선, 상세 기록은 펼쳐보기 |

가장 먼저 검증할 위험은 재미다. 6주 반복에서 선택의 의미가 드러나지 않으면 구단 수나 이벤트 수를 늘려 보완하지 않는다.
