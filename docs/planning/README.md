# 야구 선수 커리어 게임 기획 초안

킥루의 개인 커리어 구조를 참고해, 무명 신인이 출전 기회를 얻고 자기 기록을 쌓아 은퇴하는 야구 시뮬레이션을 제안한다. 가제는 **더그아웃에서 명예의 전당까지**다. 핵심은 직접 타격 조작보다 훈련, 출전, 계약의 선택으로 한 선수의 인생을 만드는 것이다.

2026-10-14 작성. 완성판 기획 상태는 **검토용 초안**이며 기획 동결을 의미하지 않는다. 사용자는 **타자·투수 개인 커리어** 방향을 선택했다. 이후 “우선 게임 만들어줘”라는 요청에 따라 [검증용 구현 범위](docs/01-planning/prototype-authorization.md)를 별도로 정하고 [플레이 가능한 웹 게임](../../README.md)을 먼저 만들었다. 아래 문서는 완성판 방향이며 체험판과 범위가 다르다.

4. [게임 규칙](docs/01-planning/game-design.md): 성장, 경기, 출전, 계약, 은퇴, 화면.

6. [요구사항](docs/01-planning/requirements.md), [백로그](docs/01-planning/backlog.md), [검토 기록](docs/01-planning/critique.md).

## 이번 기획에서 제안하는 결정

| 항목 | 제안 |
| --- | --- |
| 플레이어 | 구단주가 아닌 선수 한 명 |
| 경기 방식 | 자동 진행과 상황 요약, 중요한 선택에서 정지 |
| 첫 완성 범위 | 가상 국내 리그, 타자 또는 선발투수, 데뷔부터 은퇴 |
| 검증 순서 | 타자 6주 → 투수 6주 → 시즌 → 전체 커리어 |
| 저장 | 기기 저장과 파일 내보내기·가져오기 |
| 확장 | 해외 진출, 불펜, 국가대표, 온라인 명예의 전당 |
