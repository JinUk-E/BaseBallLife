# 더그아웃 0.3

고교의 첫 유니폼부터 40세 마지막 시즌까지 이어가는 로컬 야구 선수 커리어 게임이다. 타자 또는 선발·중계·마무리 투수로 훈련, 몸 관리, 포지션, 계약을 선택한다.

## 실행과 공유

집에서 개발을 이어갈 때는 Node.js 22 이상과 Git을 설치하고 다음을 실행한다. 외부 npm 패키지를 설치할 필요는 없다.

```sh
git clone https://github.com/JinUk-E/BaseBallLife.git
cd BaseBallLife
npm run build
npm start
```

브라우저에서 `http://127.0.0.1:4173`을 연다. 서버 없이 플레이하려면 빌드로 생성된 `play.html`을 연다. 검증은 `npm test`로 실행한다.

저장소에는 수정 가능한 `dist/` 원본을 보관한다. 생성 파일 `play.html`과 배포용 ZIP, 로컬 브라우저 프로필은 Git에 넣지 않는다. 설계·작업 맥락은 [기획 문서](docs/planning/README.md), 다음 개발 제안은 [개발 인수인계](HANDOFF.md)를 참고한다.

**`play.html`을 Chrome 또는 Edge로 열면 바로 실행된다.** `게임시작.cmd`도 같은 파일을 연다. 설치·서버·인터넷 연결이 필요 없다. 공유할 때는 `play.html` 하나만 압축해도 된다. 외부 사이트에는 게시하지 않았다.

기존 파일을 같은 위치에서 갱신하면 그 브라우저의 저장을 이어갈 수 있다. 파일 경로·브라우저가 달라지는 경우에는 게임 설정에서 저장 파일을 내보내고 새 파일에서 가져온다. 자동 저장은 각자의 기기에 남는다.

## 플레이 흐름

- **고교 시작:** 16세로 가상 학교에 입학한다. 주말 중심 28경기를 세 시즌 치르고, 성적·능력을 반영한 KBO 지명 구단에 19세로 입단한다. 고교 성적은 프로 통산과 분리한다.
- **프로 바로 시작:** 19세부터 한국·일본·미국 중 선택한 구단의 신인으로 시작한다.
- **나이와 성장:** 생성 때 정한 능력별 상한·성장 속도·회복력은 유지된다. 10대와 20대 초반에는 빠르게, 이후에는 완만하게 성장한다. 30세부터 훈련은 유지에 집중하고 잠재력·회복력·부상 이력에 따라 능력이 유지되거나 서서히 감소한다.
- **부상 완화:** 부상 발생 시 관련 능력 최대 2개만 소폭 감소한다. 한 시즌의 부상 손실은 전 능력 합계 2 이내다. 부상 기간의 반복 영구 차감은 없고 피로 자체도 능력을 영구 차감하지 않는다.
- **아이템:** 회복 키트·성장 훈련권·보호 장비를 무료 게임 포인트로 구매·사용한다. 성장 훈련권은 30세 이후에는 노화 감소를 돕는다.
- **계약:** FA 전에는 소속팀의 보류권 아래 연봉을 갱신한다. 자격 취득 후 1~4년 계약을 선택하며 계약 중에는 소속팀과 연봉을 유지한다. FA 행사를 유보하고 같은 팀에 1년 잔류할 수도 있다.
- **정규시즌 일정:** 주간 진행 화면에 날짜와 상대 팀이 표시된다. 일정·순위에서 월별 홈/원정 대진을 볼 수 있다. 휴식 주에도 훈련과 회복은 가능하다.

## 조사해서 반영한 범위

[계약 조사](CONTRACT_RESEARCH.md): KBO 고졸 첫 FA 8시즌, NPB 국내 8·해외 9시즌, MLB 6시즌을 기본으로 한다. KBO·NPB FA 재취득과 잔여 계약, MLB 연봉 조정 단계를 구분한다. 등록일수 대신 프로 완료 시즌을 서비스 1년으로 계산한다.

[일정 자료](SCHEDULE_SOURCES.md): 2026 KBO 720경기(팀당144), NPB 858경기(팀당143), MLB 2,429경기를 공식 날짜·대진으로 반영했다. MLB의 양키스·볼티모어는 최종전 취소로 각각161, 다른 구단은162경기다. 서스펜디드 1경기는 원래 날짜에 한 번 처리한다. 미래 프로 시즌은 2026 월·일을 옮긴 가상 일정으로 표시한다.

고교는 가상 8개교·28경기이며 실제 권역별 주말리그·전국대회 전체를 재현하지 않는다. 실제 선수 로스터, 트레이드, 포스팅, 보상선수, 외국인 제한과 포스트시즌은 이번 범위에 포함하지 않는다. 경기 결과·구단 전력·연봉은 게임 수치다.

[국제대회 개발 계획](INTERNATIONAL_ROADMAP.md): v0.4 U-18 → v0.5 WBC → v0.6 아시안게임 → v0.7 프리미어12·올림픽 순서와 검증 기준을 정리했다. 국제대회 경기는 아직 구현하지 않았다. 버전은 개발 순서이며 확정 출시일이 아니다.

## 이전 저장

v1/v2 저장은 검증 후 기록과 나이를 보존해 전환한다. 진행 중인 기존 시즌은 16주·112경기를 유지하며 다음 시즌부터 새 일정과 계약 구조를 적용한다. 이미 은퇴한 저장은 은퇴 상태를 유지한다. v1·v2 원본은 각각 별도 보관하고 설정에서 내보낼 수 있다. 저장 파일 가져오기와 새 선수 시작은 현재 선수의 저장을 교체한다.

## 개발·검증

최종 규칙 시험 42개를 통과했다. 24명의 19~40세 프로 전 경력 528시즌과 고교부터의 전 경력, 부상 손실 상한, FA·유보·다년 계약, 리그별 실제 경기 수, 선발 최소 5일 간격, 저장 전환을 검증했다. Edge 실제 화면에서 고교→프로·계약·일정·저장 가져오기를 확인했으며 브라우저 오류 0건, 모바일 360px 가로 넘침 0건이었다.

40개 과로 시즌에서 부상 영구 손실은 전 능력 합계 평균 0.897, 최대 2.0이었다. 균형 훈련·피로 60 초과 시 회복하는 20개 시드 표본의 첫해 평균 능력 증가는 고교 +9.34, 19세 프로 +5.15였다. 플레이 선택과 잠재력에 따라 결과는 달라진다.

- 단일 실행 파일 생성: `node export-standalone.cjs`
- 규칙 테스트: `node --test tests/*.test.cjs`
- 개발 서버: `node server.cjs` → `http://127.0.0.1:4173` (이 컴퓨터에서만 접근)
- 성장 비교 재현: `node scripts/balance.mjs`

`dist/core.js`는 게임 규칙, `league-data.js`는 구단·학교, `schedule-data.js`는 공식 일정과 개발 계획, `legacy-core.js`·`legacy-v2-core.js`는 이전 저장 검증, `app.js`는 화면·입력·저장, `styles.css`는 화면 구성을 담당한다. 외부 패키지나 원격 자산 없이 게임을 실행한다.
